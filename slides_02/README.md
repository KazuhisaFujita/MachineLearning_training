# lesson02 講義スライド

`lesson02_slides.md` がMarp形式の編集用ファイルです。全46枚で、lesson02のNotebookと併用します。

- `lesson02_slides.html`：ブラウザーで開く講義用スライド。左右の矢印キーで移動できます。
- `lesson02_slides.pdf`：配布・閲覧用。
- `assets/`：Notebookに保存されたグラフ出力から取り出した画像。

HTMLと`assets`は、同じ位置関係を保って配布してください。PDFは単独で使えます。

## 講義の進め方

冒頭のスライド4〜5で、今回扱う5種類のグラフの役割と、作図に使う主な関数を紹介します。

問いと図の見方をスライドで確認し、淡い緑の「Notebookで実習」のページでNotebookへ移ります。実習が終わったら、次のスライドに戻って結果を共有します。各実習ページには、Notebookで探す見出しと確認事項を記載しています。

| 実習スライド | Notebookの見出し | 主な確認事項 |
| --- | --- | --- |
| 9 | NumPyで配列・行列を扱う | 配列の形、行・列の平均、配列全体の計算 |
| 13 | データを準備する／データを確認する | 1行の意味、行列数、件数、欠損、基本統計量 |
| 20 | 度数分布表から分布を調べる／度数分布表をヒストグラムで表す | 表の件数と棒の高さの対応 |
| 23 | 階級を細かくしすぎるとどうなるか | 階級数による見え方の違い |
| 27 | ヒストグラムを花の種類で色分けする | 種類の分布と重なり |
| 32 | 棒グラフで種類ごとの平均を比較する／円グラフで件数を割合として見る | 平均差と構成比 |
| 36 | 散布図で2つの測定項目を組み合わせる | 1点の意味、種類の集まりと重なり |
| 41 | 折れ線グラフで月平均気温の変化を見る | 月ごとの変化、地点間の差 |
| 45 | まとめとレポート | ペンギン・アイス購入額・電力需要の演習A〜C、提出前の確認 |

講義中はNotebookを上から順に実行します。実習③では、途中の描画ライブラリの読み込みも実行します。特徴量や階級数を変更したときは、関連する表と図も再実行してください。

スライドの図はNotebookの保存済み出力の例です。受講者が変数を変えた結果は、スライドの図とは異なる場合があります。レポートには本人が選んだ設定の結果を使います。

課題A〜Cは、ペンギンの体重分布、気温とアイスクリームの平均購入額、1日の電力需要を扱います。必須の成果物は度数分布表1つとグラフ3つ（ヒストグラムの比較図・散布図・折れ線グラフ）です。演習Aでは階級数4・8・16の比較と、見やすいと思った設定・理由の記載も必須です。課題の各セルは単独で実行できます。CSVは手元になければコードがGitHubから取得し、日本語表示には`japanize-matplotlib`を使います。月平均気温の読み込みセルもCSVの自動取得に対応しています。

各グラフの前に、作図の要点を示すコード例があります。ライブラリ・データ・種類の順番と配色はNotebookで準備し、コード例を読んでから図を確認します。タイトルなどの詳細を含む完全な実行コードはNotebookを参照してください。

講師向けの補足はMarkdown内のHTMLコメントにあります。Marpの発表者ビューでも確認できます。巻末の発展例はスライドの基本学習に含めず、Notebookを参照する形にしています。

## 編集と書き出し

VS Codeの「Marp for VS Code」でMarkdownを開くとプレビューできます。コマンドで書き出す場合は、Node.jsとMarp CLIを使い、リポジトリのルートで実行します。

```sh
npx @marp-team/marp-cli slides_02/lesson02_slides.md --html -o slides_02/lesson02_slides.html
npx @marp-team/marp-cli slides_02/lesson02_slides.md --html --pdf --allow-local-files -o slides_02/lesson02_slides.pdf
```

PDFの書き出しにはChromeなどの対応ブラウザーが必要です。HTMLタグを使った文字サイズ指定を含むため、`--html`を付けています。

## 図とデータの出典

すべての図は、`../notebook/lesson02_eda_template.ipynb` に保存された出力から取得しています。画像とコードを見比べ、初期設定の花びらの長さ・18階級、花びらの長さと幅の散布図、および同梱の気温CSVに対応する例として使用しています。

- Iris：Notebookで読み込むscikit-learn同梱データ。
- 気温：`../notebook/datasets/monthly_mean_temperature_2025.csv`。気象庁の広島・津山・金沢の2025年月平均気温。一次出典と転記条件は `../notebook/datasets/README.md` に記載。
- スライド17の度数分布表は、Irisの花びらの長さを18階級に分けた実データの集計。
- スライド14の平均の例、スライド15の度数分布表は説明用データ。Iris全体の集計ではありません。

Notebookの図を更新した場合は、対応する画像も更新してからHTMLとPDFを書き出してください。
