# lesson02 講義スライド

`lesson02_slides.md` がMarp形式の編集用ファイルです。全35枚で、lesson02のNotebookと併用します。既存のNotebookは変更していません。

- `lesson02_slides.html`：ブラウザーで開く講義用スライド。左右の矢印キーで移動できます。
- `lesson02_slides.pdf`：配布・閲覧用。
- `assets/`：Notebookに保存されたグラフ出力から取り出した画像。

HTMLと`assets`は、同じ位置関係を保って配布してください。PDFは単独で使えます。

## 講義の進め方

問いと図の見方をスライドで確認し、淡い緑の「Notebookで実習」のページでNotebookへ移ります。実習が終わったら、次のスライドに戻って結果を共有します。各実習ページには、Notebookで探す見出しと確認事項を記載しています。

| 実習スライド | Notebookの見出し | 主な確認事項 |
| --- | --- | --- |
| 7 | NumPyで配列・行列を扱う | 配列の形、行・列の平均、配列全体の計算 |
| 11 | データを準備する／データを確認する | 1行の意味、行列数、件数、欠損、基本統計量 |
| 15 | 度数分布表から分布を調べる／度数分布表をヒストグラムで表す | 表の件数と棒の高さの対応 |
| 17 | 階級を細かくしすぎるとどうなるか | 階級数による見え方の違い |
| 20 | ヒストグラムを花の種類で色分けする | 種類の分布と重なり |
| 23 | 棒グラフで種類ごとの平均を比較する／円グラフで件数を割合として見る | 平均差と構成比 |
| 26 | 散布図で2つの測定項目を組み合わせる | 1点の意味、種類の集まりと重なり |
| 30 | 折れ線グラフで月平均気温の変化を見る | 月ごとの変化、地点間の差 |
| 34 | まとめとレポート | 演習A〜C、提出前の確認 |

初回はNotebookを上から順に実行します。実習③では、途中の描画ライブラリの読み込みも実行します。特徴量や階級数を変更したときは、関連する表と図も再実行してください。

スライドの図はNotebookの保存済み出力の例です。受講者が変数を変えた結果は、スライドの図とは異なる場合があります。レポートには本人が選んだ設定の結果を使います。

講師向けの補足はMarkdown内のHTMLコメントにあります。Marpの発表者ビューでも確認できます。巻末の発展例はスライドの基本学習に含めず、Notebookを参照する形にしています。

## 編集と書き出し

VS Codeの「Marp for VS Code」でMarkdownを開くとプレビューできます。コマンドで書き出す場合は、Node.jsとMarp CLIを使い、リポジトリのルートで実行します。

```sh
npx @marp-team/marp-cli slides_02/lesson02_slides.md --html -o slides_02/lesson02_slides.html
npx @marp-team/marp-cli slides_02/lesson02_slides.md --html --pdf --allow-local-files -o slides_02/lesson02_slides.pdf
```

PDFの書き出しにはChromeなどの対応ブラウザーが必要です。HTMLタグを使った文字サイズ指定を含むため、`--html`を付けています。

## 図とデータの出典

すべての図は、`../notebook/lesson02_eda_template.ipynb` に保存された出力から取得しています。画像とコードを見比べ、初期設定の花びらの長さ・18階級、花びらの長さと幅の散布図、および同梱の気温CSVに対応する例として使用しています。

- Iris：Notebookで読み込むscikit-learn同梱データ。
- 気温：`../notebook/data/monthly_mean_temperature_2025.csv`。気象庁の広島・津山・金沢の2025年月平均気温。一次出典と転記条件は `../notebook/data/README.md` に記載。
- スライド12の平均の例、スライド13の度数分布表は説明用データ。Iris全体の集計ではありません。

Notebookの図を更新した場合は、対応する画像も更新してからHTMLとPDFを書き出してください。
