# Machine Learning Training Curriculum

機械学習の基礎を体系的に学ぶためのカリキュラムです。

## スケジュール (Schedule)

| 回 | テーマ | 内容 |
| :--- | :--- | :--- |
| 第1回 | ガイダンス | 班分け、イントロダクション |
| 第2回 | Python基礎・導入 | 変数、制御構文、Notebookの使い方 |
| 第3回 | 可視化とEDA | ヒストグラム、散布図を用いた探索的データ分析 |
| 第4回 | 回帰分析 (講義) | 数値予測の考え方、線形回帰の概念 |
| 第5回 | 回帰分析 (演習) | 実践的な回帰モデルの構築と評価 |
| 第6回 | 分類の基礎 (講義) | カテゴリ予測の概念、混同行列の仕組み |
| 第7回 | 分類の基礎 (演習) | 分類モデルの構築と精度の評価 |
| 第8回 | ニューラルネットワーク (講義) | 基本構造、重み、活性化関数の理解 |
| 第9回 | ニューラルネットワーク (演習) | 小規模なNNの構築と学習曲線の観察 |
| 第10回 | CNNによる画像分類 (講義) | 画像データの特性、畳み込みの仕組み |
| 第11回 | CNNによる画像分類 (演習) | CNNモデルの構築と誤分類の考察 |
| 第12回 | クラスタリング (講義) | 教師なし学習、データのまとまりの発見 |
| 第13回 | クラスタリング (演習) | クラスタリングの実装とPCAによる可視化 |
| 第14回 | 発表準備 | 興味を持った分析のまとめ |
| 第15回 | 発表会 | 分析結果のプレゼンテーション |
