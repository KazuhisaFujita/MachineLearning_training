# lesson03 講義スライド

`lesson03_slides.md` がMarp形式の編集用ファイルです。全50枚で、lesson03のNotebookと併用します。slides_02と同じ16:9のサイズ・配色・書体・実習ページの形式です。

- `lesson03_slides.html`：ブラウザーで開く講義用スライド。左右の矢印キーで移動できます。
- `lesson03_slides.pdf`：配布・閲覧用。
- `assets/`：教材データから描画した図と、評価表の計算値。

HTMLと`assets`は、同じ位置関係を保って配布してください。PDFは単独で使えます。

## 前回の講義との接続

リポジトリ直下の `03_regression.pdf`（2026年10月27日版）を受講済みの学生を想定しています。前回の「可視化して回帰直線を引く」から、今回は「Pythonで学習・予測し、未使用の期間で確かめる」へ進みます。

- スライド9で記号の違いを対応付けます。前回の実測値 $t$・予測値 $y$・傾き $a$ は、今回とNotebookでは $y$・$\hat{y}$・$w$ です。
- スライド12で `fit` と `predict` の入力と役割、19〜20でテストデータが必要な理由と学習・テストの流れを確認します。
- 前回の平均二乗誤差と最小二乗法を15で復習し、33で平方根をとったRMSEへつなげます。評価指標はRMSEに統一しています。
- 26〜28で重回帰の入出力・式・表せる関係を確認し、37〜38では図の軸・基準線・残差の符号を言葉と対応させます。

## 講義の進め方

相関、ペンギンの単回帰、アイスクリームの単回帰・重回帰、予測の評価の順に進みます。19で未知データで評価する理由、28で重回帰が表せる関係、40〜41で夏・冬の過小予測と、気温による購入額の増え方の違いを確認します。2011年1月の実測346円・単回帰の予測約196円を例に、点と回帰直線の上下関係からずれを読み取ります。考察では図で観察できることと理由についての推測を分け、非線形性の説明を必須にはしていません。淡い緑の「Notebookで実習」でNotebookへ移り、実行後にスライドへ戻って結果を共有します。

| 実習スライド | Notebookの見出し | 確認すること |
| --- | --- | --- |
| 8 | 2. 散布図と相関係数 | 関係の向き・強さと、相関だけでは捉えにくい曲線 |
| 16 | 3. ペンギンの翼の長さと体重で単回帰を試す | 傾き・切片・入力を変えた予測 |
| 21 | 4. アイスクリームのデータを読む／5. 学習期間とテスト期間を分ける | 1行の意味と、学習96件・テスト24件の分割 |
| 25 | 6. 気象データと購入額の関係を見る／7. 気温から購入額を予測する（単回帰） | 相関と回帰式、範囲内での予測 |
| 31 | 8. 複数の気象変数を使う（重回帰） | 係数の意味・単位と、説明変数どうしの相関 |
| 36 | 9. 学習に使わなかった期間で評価する | RMSEと、4つの方法の比較 |
| 39 | 10. 予測と実測を図で比べる／残差から予測のずれを読む | 過大予測・過小予測と、ずれが大きい時期 |
| 48 | まとめとレポート／演習A・B | 電力需要の演習と提出前の確認 |

スライド43〜44で電力需要データの範囲と単位を確認し、45〜46で演習A・Bを説明します。`notebook/datasets/tepco_power_weather_2024_2025.csv` を使い、東京エリアの1時間平均電力需要を、東京観測地点の気温・相対湿度・日照時間から推定します。使用する列に欠測のある1行を除外し、Aは2年分全体の17,543時間、Bは2024年の8,783時間を学習用、2025年の8,760時間をテスト用に使います。

Aでは散布図・回帰直線・相関係数から関係を説明します。Bでは気温だけの単回帰と3変数の重回帰のRMSE（万kW）を比較し、時系列図か比較図を1つ選んで、読み取れたことを2〜3文で説明します。折れ線のみ日平均にまとめ、散布図・学習・RMSEは1時間ごとの値を使います。平均による2つの基準と係数表は参考表示です。重回帰での改善は前提としません。完全な実行コードとレポート本文のテンプレートはNotebookにあります。

元データは1時間区間の終わりの気象と結合しています。気象の観測値が分かった条件での推定であり、実際の事前予測とは利用できる情報が異なります。出典と時刻・欠測の扱いは `../notebook/datasets/README.md` を参照してください。

学習と評価の図は、初期設定を実行した例です。受講者が入力や設定を変えた場合は、自分の結果をレポートに使います。スライド中の短いコードは要点のみで、本文の事前セルを実行して使うものです。演習A・Bのコードセルは、それぞれ単独で実行できます。

講師向けの補足と出典は、MarkdownのHTMLコメントにも記載しています。Notebook巻末の発展演習は、基本講義のスライドには含めていません。

## 編集と書き出し

VS Codeの「Marp for VS Code」でMarkdownを開くとプレビューできます。Node.jsとMarp CLIを使う場合は、リポジトリのルートで次を実行します。

```sh
npx @marp-team/marp-cli slides_03/lesson03_slides.md --html -o slides_03/lesson03_slides.html
npx @marp-team/marp-cli slides_03/lesson03_slides.md --html --pdf --allow-local-files -o slides_03/lesson03_slides.pdf
```

PDFの書き出しにはChromeなどの対応ブラウザーが必要です。HTMLタグを使用しているため、`--html`を付けています。

ペンギンは[Palmer Penguins](https://allisonhorst.github.io/palmerpenguins/)（CC0）です。演習の電力需要は東京電力パワーグリッド「でんき予報」、気象は気象庁の観測値です。アイスクリームは既存教材から引き継いだデータで、地域・購入額の集計対象・一次出典は不明です。詳しい列・期間・取得条件は `../notebook/datasets/README.md` を参照してください。

Notebookのコードやデータを変更した場合は、対応する画像・評価表も更新してからHTML・PDFを書き出してください。
