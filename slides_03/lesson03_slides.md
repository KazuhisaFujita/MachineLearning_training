# 単回帰の式

説明変数が1つの線形回帰を **単回帰** と呼びます。
傾き $w$ と切片 $b$ は、データから決める **パラメータ** です。

$$\hat{y} = wx + b$$

| 記号 | 意味 | ペンギンの例 |
| --- | --- | --- |
| $x$ | 入力 | 翼の長さ（mm） |
| $\hat{y}$ | 予測値 | 体重の予測値（g） |
| $w$ | 傾き | 1mm長い入力での予測値の変化 |
| $b$ | 切片 | 入力が0のときの式の値 |

# 傾きと切片の読み取り

体重の予測値（g） ≈ **32.83 × 翼の長さ（mm） − 2535.84**

- 傾きは約32.83 g/mm
- 翼が1mm長い入力では、予測値が約32.83g大きくなる
- 190mmでの予測は約3702.2g

切片は翼の長さ0mmでの式の値です。

**観測範囲外なので、実際の体重として解釈しません。**

# 学習：二乗したずれを小さくする

実測値と予測値の **ずれの2乗の合計** が最小になるように、傾きと切片を求めます。

$$\sum_{i=1}^{n}(y_i-\hat{y}_i)^2$$

- $y_i-\hat{y}_i$ は、$i$ 番目の実測値と予測値のずれ
- 正負が打ち消し合わないよう、ずれを2乗して足す
- `fit(X, y)` が、この計算に基づいて係数を求める

この方法を **最小二乗法** と呼びます。

<p class="small">n は学習データの件数。同じデータでは、合計を最小にする係数と、前回の平均二乗誤差を最小にする係数は同じです。</p>

# 重回帰の式とコード

説明変数を複数使う線形回帰を **重回帰** と呼びます。

$$\hat{y} = w_1x_1 + w_2x_2 + \cdots + w_px_p + b$$

$p$ は説明変数の数で、今回は $p=4$ です。<br>気温・降水量・湿度・高温日数を使います。

```python
multi_model = LinearRegression()
```

説明変数を増やしても、未知データの誤差が必ず減るとは限りません。

# 重回帰で表せる関係

ここで使う重回帰は、**各入力に係数を掛けて足し、切片を加える式** です。

| 説明変数の数 | 予測の式の形 |
| --- | --- |
| 1つ | 直線 |
| 2つ | 空間上の平面 |
| 3つ以上 | 平面と同じ考え方を、より多くの変数へ広げたもの |

説明変数を増やしても、曲線的な関係を十分に表せるとは限りません。

# 重回帰の係数の意味

気温の係数は、基本設定で **約17.52円/℃** です。

> 他の3つの入力を固定すると、気温が1℃高い入力で
> 購入額の予測値が約17.52円増える。

- 他の変数も含めた式の性質を表す
- 単位や値の広がりが異なるため、係数の絶対値だけで重要度を比べない
- 係数を、その変数の因果効果とは解釈しない

---

# 相関と重回帰の係数

学習期間では、湿度と購入額の相関は正、重回帰の湿度の係数は負です。

| 見ているもの | 関係の捉え方 |
| --- | --- |
| 相関 | 2つの変数だけの関係 |
| 重回帰の係数 | 他の説明変数を固定した式の関係 |

**2つの変数を見るときと、他の入力も含めた式では、符号が違う場合があります。**

<p class="small">補足：説明変数どうしに強い直線的な関係がある状態を多重共線性と呼びます。係数が不安定になることがあるため、係数の符号だけで原因を判断しません。</p>

# 小さな例で誤差を確かめる

前回の「誤差」と同じく、**実測値 − 予測値** を残差と呼びます。

| 実測値（円） | 予測値（円） | 残差（円） | 残差の2乗（円²） |
| ---: | ---: | ---: | ---: |
| 500 | 400 | +100 | 10,000 |
| 500 | 600 | −100 | 10,000 |
| 500 | 200 | +300 | 90,000 |

+100円は100円の過小予測、−100円は100円の過大予測です。
正負が打ち消し合わないよう、学習時と同じく2乗して集計します。

---

# 二乗誤差で評価する：RMSE

RMSEは、**平均二乗誤差の平方根** です。単位は元の円に戻ります。
学習と同じ二乗誤差に基づき、**テスト期間**の予測を評価します。

$$RMSE = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2}$$

- ずれ → 2乗 → 平均 → 平方根、の順に計算する
- 小さいほど良い。大きなずれの影響を強く受ける
- 先ほどの例：$\sqrt{(10000+10000+90000)/3}\approx 191.5$ 円

<p class="small">RMSEが100円でも、すべての月の誤差が100円以内という意味ではありません。</p>

---

# 比較する簡単な予測方法

回帰モデルと一緒に、**平均を使う2つの基準** も評価します。

| 方法 | 予測に使う値 |
| --- | --- |
| 学習期間の平均 | 96か月の購入額の平均を毎月予測 |
| 学習期間の同じ月の平均 | 例えば7月なら、学習期間の7月の平均 |
