# 東京エリアの電力需要と東京の気象（2024〜2025年・lesson03の課題）

`tepco_power_weather_2024_2025.csv` は、東京電力パワーグリッド「でんき予報」の電力データを2024〜2025年の2年分に拡張し、気象庁の東京観測地点の時別データを結合したものです。既存の `tepco_power_usage_202508.csv` はそのまま保存しています。lesson03の演習A・Bで使用します。気温・相対湿度・日照時間を使い、必要な列に欠測がある1行を除いた17,543時間を対象にします。Aは2年分全体の関係を調べ、Bは2024年の8,783時間で学習し、2025年の8,760時間で評価します。

- 期間・件数: 2024年1月1日0時台〜2025年12月31日23時台。1行が1時間で、17,544行・18列（2024年8,784時間、2025年8,760時間）。2024年はうるう年です。
- 電力需要は東京エリア全体、気象は東京の1観測地点（`s47662`、地点番号47662、都府県番号44）の値です。気象はエリア全体の平均ではありません。
- 電力には日時の重複・欠落・欠損がありません。気象との結合も全行で成功しています。2025年8月の電力の4つの数値列は、既存教材の744行とすべて一致しています。
- 文字コード: UTF-8（BOM付き）。取得日: 2026年10月30日。公開値は後日修正される場合があります。

## 列と単位

| 列 | 内容 |
| --- | --- |
| `日時` | 電力の集計区間の開始日時（日本標準時） |
| `DATE`・`TIME` | 電力の元CSVの日付・時刻 |
| `当日実績(万kW)` | その1時間の平均電力需要。回帰で予測する値として使う |
| `予測値(万kW)` | 東京電力が公表した予測値。学生が作る回帰モデルの予測値とは別のもの |
| `使用率(%)`・`供給力(万kW)` | 電力の元CSVに含まれる使用率・供給力 |
| `気象観測日時` | 電力の区間開始から1時間後の、気象庁の観測日時 |
| `東京_気温(℃)` | 区間終了時の気温。1時間の平均気温ではない |
| `東京_相対湿度(%)` | 区間終了時の相対湿度 |
| `東京_降水量(mm)` | その区間の前1時間降水量（雨・雪などを水量として観測） |
| `東京_風速(m/s)` | 区間終了時刻前10分間の平均風速 |
| `東京_日照時間(h)` | その区間の前1時間の日照時間。0〜1時間 |
| 各気象列の末尾が `_品質情報` の5列 | 気象庁の品質情報。今回のデータでは8が正常値、1が欠測 |

## 時刻の合わせ方

日時はすべて日本標準時です。電力の `TIME = 0:00` は0時〜1時の1時間平均需要です。気象の降水量・日照時間は、観測日時までの前1時間の値なので、同じ区間になるよう **電力の区間開始日時 + 1時間 = 気象観測日時** で結合しています。

例えば、電力の `2025-08-01 00:00:00` には、気象の `2025-08-01 01:00:00` を対応させています。各日の23時台には、翌日0時の気象を対応させます。気温・湿度は区間終了時の観測値、風速は区間終了前10分の平均であり、電力と同じ長さの時間平均値ではありません。

このデータは、気象の観測値が分かった条件で需要との関係を調べるためのものです。1時間前や前日に実際の予測を行う場合は、その時点で利用できる情報だけで入力を作る必要があります。

## 欠測と分析時の扱い

- 気温1件、相対湿度1件、風速4件が欠測で、欠測を含む行は合計5行です。元の欠測を空欄で保存し、補間や削除はしていません。降水量・日照時間には欠測がありません。
- 使う説明変数に欠測がある行だけを除外してください。単回帰と重回帰のRMSEを比較する場合は、同じテスト行にそろえます。
- `予測値(万kW)`・`使用率(%)`・`供給力(万kW)` は、気象から需要を推定する演習の説明変数には使わず、元データの情報として残しています。特に使用率は需要実績と関係する数値で、予測時点で得られる情報とは限りません。
- 時刻・季節・曜日などによっても需要が変わることを、図を見ながら考察できます。曜日だけで祝日やお盆などの営業日・休業日を断定しないでください。
- 年を分けて評価する場合は、2024年を学習、2025年をテストとする構成が可能です。結果に合わせて期間を選び直さず、使った期間を明記してください。

- 気象はすべて東京の1観測地点（`s47662`）です。東京都区部の支出額は同地域の気象との対応を確認するために使います。全国の支出額・数量に対しては、東京の気温を季節変化の参考指標として組み合わせています。全国平均の気温と同一視しないでください。

- 全ファイルで月の重複・欠落・数値の空欄はありません。気象の正常値（品質8）と準正常値（品質5）を使用し、品質情報を残しています。準正常値を黙って正常値に置換したり、値の補間をしたりしていません。
- `年`・`月` は年月から取り出した値、`12月フラグ` は12月なら1、それ以外なら0です。目的変数から計算した特徴量ではありません。
- 気象はその月の観測値です。月が始まる前に予測する場合には、その時点で使える気象情報を用いる必要があります。
- 家計調査の選択条件は、品目「3X4 ビール」（内部コード `011100030`）、世帯「二人以上の世帯（2000年〜）」（`03`）。地域は全国（`00000`）または東京都区部（`13003`）です。
- 文字コードはUTF-8（BOM付き）。取得日: 2026年10月30日。

## 試行結果

最初に2015〜2022年の96か月で学習し、2023〜2024年の24か月で候補を比較しました。その後、同じモデルのまま2025年の12か月でも確認しています。全国の支出額についてのRMSE（円）は次の通りです。

| 方法 | 2023〜2024年 | 2025年 |
| --- | ---: | ---: |
| 学習期間の平均 | 262.3 | 288.6 |
| 学習期間の同じ月の平均 | 150.4 | 234.2 |
| 気温だけの単回帰 | 232.7 | 276.2 |
| 気温・湿度・降水量の重回帰 | 228.5 | 264.1 |
| 気温・12月フラグの重回帰 | 134.2 | 231.5 |

気温だけでは年末の支出の山を捉えにくく、12月の情報を加えたモデルは2023〜2024年に改善しました。ただし2025年では誤差が増え、年による支出水準の変化も見られます。東京都区部の支出額と全国の購入数量でも、気象変数だけによる改善は小さい結果でした。結果のよい月だけを除外・採用する処理はしていません。

2025年を確認した後の追加検討として、2015〜2024年で「気温・12月フラグ・年」のモデルを学習すると、2025年のRMSEは167.9円でした。これは試行後のモデル変更なので、独立な最終評価としては扱いません。
