# lesson04 講義スライド

`lesson04_slides.md` がMarp形式の編集用ファイルです。全39枚で、lesson04のNotebookと併用します。slides_02・slides_03と同じ16:9のサイズ・配色・書体・実習ページの形式です。

- `lesson04_slides.html`：ブラウザーで開く講義用スライド。左右の矢印キーで移動できます。
- `lesson04_slides.pdf`：配布・閲覧用。
- `assets/`：教材データから描画した図と、評価表の計算値。

HTMLと`assets`は、同じ位置関係を保って配布してください。PDFは単独で使えます。

## 前回の講義との接続

lesson03（回帰）を受講済みで、リポジトリ直下の `08_classification.pdf`（講義資料1「分類1: k近傍、線形識別モデル」）と `09_classification.pdf`（講義資料2「分類2: ロジスティック回帰、決定理論」）を配布できる状態を想定しています。前回の「数値を予測する」から、今回は「種類を予測する」へ進みます。

- スライド2で回帰と分類の違いを対応付けます。lesson02で使ったIrisの実測データに、花弁の長さと幅の2列だけで戻ります。
- スライド5で講義資料1の1-of-K coding、17〜20で線形識別モデル（フィッシャーの線形判別）を対応させます。
- スライド13で「回帰直線」と「決定境界」の意味の違いを明示します。回帰では出てこない概念です。
- スライド23〜27で講義資料2のロジスティック回帰・最尤推定・クロスエントロピー誤差・L2正則化に対応します。第7節はlesson05のニューラルネットワークにそのままつながります。
- スライド31〜36の混同行列は、ノートブック第8節の実行結果そのものです。決定理論（しきい値・棄却）には、スライド39で次回以降の接続先として触れるだけに留めています。

## 講義の進め方

散布図、kNN、フィッシャーの線形判別、テストでの評価、ロジスティック回帰の予測確率、混同行列の順に進みます。8で`stratify`による分割、14〜15でkによる境界と正解率の変化（「学習用によく合うこと」と「未知データで当たること」の違いはlesson05でも中心になります）、19で境界の直線へ数値を代入した判定、24〜25でシグモイドの形と仕切り $a=0$ が $p=0.5$ に対応する読み取り、29で確率の中間値の花が境界付近の帯にいることの観察、33〜35で4マスからの指標導出と「1つの指標だけでは評価できない」こと（悪意の分類器の例）を確認します。淡い緑の「Notebookで実習」でNotebookへ移り、実行後にスライドへ戻って結果を共有します。

| 実習スライド | Notebookの見出し | 確認すること |
| --- | --- | --- |
| 8 | 3. まず散布図を読む | 2種類の集まりと重なり |
| 16 | 4. k近傍法（kNN） | 近傍5輪の多数決と境界 |
| 22 | 5. フィッシャーの線形判別／6. 確かめる | 直線の境界とテスト正解率 |
| 30 | 7. ロジスティック回帰 | シグモイドの形と予測確率 |
| 37 | 8. 混同行列 | 4マスの内訳と指標、3モデル比較 |

レポートはノートブック「振り返りとレポート」の1〜5をA4 1ページ程度にまとめるもので、スライド39に項目を載せています。しきい値の移動は決定理論（講義資料2）、3種類以上への拡張はこれからの講義で扱います。ノートブックに発展節はありません。

学習と予測の図・表の数値は、すべてNotebookを初期設定のまま実行した結果です（例: テスト30輪の正解率 kNN 0.900 / フィッシャー 0.867 / ロジスティック回帰 0.900、kNNとロジスティック回帰は4マスの内訳も同じ）。受講者が設定を変えた場合は、自分の結果をレポートに使います。講師向けの補足と出典は、MarkdownのHTMLコメントにも記載しています。

## 編集と書き出し

VS Codeの「Marp for VS Code」でMarkdownを開くとプレビューできます。Node.jsとMarp CLIを使う場合は、リポジトリのルートで次を実行します。

```sh
npx @marp-team/marp-cli slides_04/lesson04_slides.md --html -o slides_04/lesson04_slides.html
npx @marp-team/marp-cli slides_04/lesson04_slides.md --html --pdf --allow-local-files -o slides_04/lesson04_slides.pdf
```

PDFの書き出しにはChromeなどの対応ブラウザーが必要です。HTMLタグを使用しているため、`--html`を付けています。

## 図と数値の出典

`../notebook/lesson04_classification_basic_template.ipynb` の本文コードセルを順番に再実行して作成しています。Notebookファイルの保存済み出力には依存せず、図は軸範囲・色・乱数シード（`random_state=42`）までNotebookと同一です。再生成はリポジトリのルートで次を実行します（Matplotlib・scikit-learnが必要）。

```sh
.venv/bin/python slides_04/assets/generate_slides_assets.py
```

- `train_scatter.png`：学習用70輪の散布図（スライド6）。
- `knn_votes.png`：新しい花（花弁の長さ5.0cm・幅1.7cm）に最も近い5輪と投票（スライド10）。
- `knn_boundary.png`：kNN（k=5）の決定境界（スライド12）。
- `k_boundaries.png`：k=1, 3, 5, 11, 21, 47の境界と学習用・検証用の正解率（スライド14）。学習用49輪・検証用21輪は学習用70輪の中の分割です。
- `k_accuracy.png`：kと正解率の折れ線（スライド15）。
- `boundary_compare.png`：フィッシャーとkNNの境界の並べ比べ（スライド18）。
- `test_compare.png`：テスト用30輪の予測と誤分類（スライド20）。
- `sigmoid.png`：シグモイド関数σの形と σ(±2)・σ(±5) の値（スライド24）。
- `prob_map.png`：格子各位置での予測確率 p(virginica) のグラデーション（スライド28）。
- `metrics.json`：同じ実行で計算した値。3モデルの学習用・テスト正解率とTP・FP・FN・TN、Precision・Recall・specificity・false positive率、LDAとロジスティック回帰の係数・切片、2種類の中心、k比較表。スライド15・19・27・31〜36の表の数値はこのファイルと一致します。

データはscikit-learnの`load_iris()`に含まれるIrisの実測データ（R.A. Fisher, 1936）で、`versicolor`と`virginica`の各50輪のみを使います。列・分割の詳細はNotebook第2節を参照してください。

Notebookのコードやデータを変更した場合は、`generate_slides_assets.py`で図と`metrics.json`を更新してから、HTML・PDFを書き出してください。
